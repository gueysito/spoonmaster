# Demo plan

Use a real source-led request and actual retrieved evidence. Do not invent a fast
run, meal feedback or implemented roadmap feature for the recording.

1. Ask for food in a neighborhood, without coordinates or onboarding.
2. Show a meaningful research update, then the distinct alternatives and Maps links.
3. Open `/why` to show what was compared and which facts remain uncertain.
4. Give clearly labeled demo taste feedback after opt-in and show the saved change.
5. Optionally show a confirmed companion subset or a different city's source guidance.

The submission recording length and deadline need confirmation against the current
organizer instructions before submission. Voice and Telegram demonstrations require
those surfaces; the CLI demo should show normal text, not promise separate cards.
